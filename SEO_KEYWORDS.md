## Chrome Web Store Optimization Tips

### 1. Title Optimization
- Include primary keywords: "AI Prompt Navigator - Export & Organize AI Chats"
- Keep under 45 characters for full visibility
- Use descriptive subtitle

### 2. Short Description (132 chars)
- "Export ChatGPT, Claude & Gemini conversations to Markdown, PDF, JSON, HTML, or Text. Copy full chats as Markdown to continue context."
- Includes: Export, ChatGPT, Claude, Gemini, Markdown, PDF, JSON, HTML, Text, Copy, Continue context

### 3. Detailed Description
- Use headings with keywords
- Include feature lists with keywords
- Add use cases with long-tail keywords
- Include platform names multiple times
- Add "Keywords" section at the end

### 4. Screenshots (Recommended)
- Screenshot 1: Main popup showing export options
- Screenshot 2: PDF export example
- Screenshot 3: Markdown copy feature
- Screenshot 4: Multi-platform support (ChatGPT, Claude, Gemini)
- Screenshot 5: Navigation feature (Prompts Nav)

### 5. Promotional Images
- Feature export formats prominently
- Show multi-platform support
- Highlight "Copy as Markdown" feature
- Show PDF export quality
